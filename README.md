# DevAesthetic — Developer New Tab Chrome Extension

A premium developer-focused Chrome extension that transforms your new tab into a beautiful, productive workspace.

## Features

- **8 Stunning Themes** — Midnight, Cyberpunk, Monokai, Nord, Dracula, Ocean, Aurora, Sunset
- **5 Wallpaper Styles** — Mesh Gradient, Waves, Starry Night, Matrix, Minimal
- **Animated Particle Background** — Connected particle network with smooth animations
- **Live Clock** — 24H/12H format with seconds, date, and contextual greetings
- **Multi-Engine Search** — Google, GitHub, Stack Overflow, npm, MDN, DuckDuckGo
- **Quick Links** — Fast access to dev sites (customizable)
- **Pomodoro Timer** — Built-in productivity timer with session tracking
- **System Info** — Battery, memory, and connection status
- **Quick Notes** — Auto-saved notepad
- **Daily Quotes** — Developer inspiration
- **Command Palette** — `Ctrl+K` to open, type commands
- **Keyboard Shortcuts** — Power-user navigation
- **Grid Overlay** — Subtle developer-aesthetic grid pattern
- **Glass Morphism UI** — Backdrop blur and translucent cards

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in top-right)
3. Click **Load unpacked**
4. Select the `dev-aesthetic-extension` folder
5. Open a new tab — enjoy!

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Open Command Palette |
| `Ctrl+,` | Open Settings |
| `Ctrl+Shift+T` | Cycle themes |
| `Escape` | Close any panel |
| `>command` in search | Execute command |

## Customization

- Click the gear icon (top-right) for Settings
- Click the image icon for Wallpaper picker
- Click the extension icon in toolbar for quick controls
- Add custom quick links with the "+" button
